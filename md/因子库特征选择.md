# 因子库与特征选择

本平台支持**自定义筛选特征**进行回测，并提供可扩展的**因子库接口**，为将来维护
成千上万因子预留了清晰的接入方式。

---

## 1. 功能概述

- **默认特征集**：`Alpha158`（158 个因子）、`Alpha360`（360 个因子，6 字段 × 60 历史）。
- **自定义特征**：可以在页面上**多选勾选**某个特征集里的具体特征（如只选 `KMID`、`ROC5`、`MA20` 等），回测时仅使用这些特征。
- **公式提示**：鼠标悬停在特征名上，可查看该因子的**具体表达式**与说明。
- **全量 / 子集**：不勾选任何特征（或勾选全部）时，等价于使用该特征集全量；勾选子集时只计算所选特征。

---

## 2. 因子目录接口（后端）

### 2.1 获取可用特征集

```
GET /api/factors/datasets
```

响应：

```json
{
  "datasets": [{"name": "Alpha158"}],
  "default": "Alpha158"
}
```

### 2.2 获取特征集目录

```
GET /api/factors/catalog?dataset=Alpha158
```

响应（每条因子含 名称 / 表达式 / 分类 / 描述）：

```json
{
  "dataset": "Alpha158",
  "total": 158,
  "groups": [
    {
      "group": "K线形态",
      "fields": [
        {
          "name": "KMID",
          "expression": "($close-$open)/$open",
          "category": "K线形态",
          "description": "K线中段：收盘相对开盘涨跌幅"
        }
      ]
    }
  ],
  "flat": [
    { "name": "KMID", "expression": "($close-$open)/$open", "category": "K线形态", "description": "..." }
  ]
}
```

- `groups`：按分类分组，方便前端分区展示。
- `flat`：扁平列表，方便程序化处理。

### 2.3 回测时提交自定义特征

在回测请求 `BacktestRequest` 中增加字段：

```json
{
  "feature": "Alpha158",
  "selected_features": ["KMID", "KLEN", "ROC5", "ROC20", "MA20", "STD10", "BETA20", "CORR20", "MAX60", "VMA20"]
}
```

- `selected_features` 为空 / `null`：使用该特征集全量。
- 非空：仅计算这些特征。后端会用 `SelectedAlpha158` / `SelectedAlpha360` Handler 过滤。

---

## 3. 前端操作

1. 在"特征集"下拉选择 `Alpha158` 或 `Alpha360`。
2. 点击 **"自定义筛选特征"** 展开面板。
3. 在面板中按分类**勾选 / 取消**特征；鼠标悬停特征名可看公式。
4. 可"全选 / 清空"。已勾选数量显示在面板顶部。
5. 提交回测即按所选特征执行。

> 复用历史回测参数时，若该次回测用了自定义特征，会自动带出并展开面板。

## 4. 如何扩展因子库（重要）

设计为"Provider + Registry"方式，新增因子**不需要改接口和前端**。

### 目录结构

```
backend/app/factors/
├── catalog.py     # 因子目录：Provider 函数 + 注册表 FACTOR_PROVIDERS
├── handler.py     # 支持 fields 子集的自定义 Handler（SelectedAlpha158/360）
└── (可新增更多 provider 文件)
```

### 步骤一：新增一个 Provider 函数

在 `catalog.py`（或新增文件）中定义一个函数，返回因子记录列表，每条包含：

```python
def my_factor_provider():
    return [
        {
            "name": "MYF1",                 # 因子名（全局唯一，回测时用）
            "expression": "Ref($close,5)/$close",   # qlib 表达式
            "category": "自研动量",          # 分类（用于前端分组展示）
            "description": "5日动量因子",
        },
        # ... 更多因子
    ]
```

### 步骤二：在注册表中登记

```python
FACTOR_PROVIDERS = [
    {"dataset": "Alpha158", "provider": _alpha158_provider, "grouping": "category"},
    {"dataset": "MyFactors", "provider": my_factor_provider},   # ← 新增
]
```

前端 `GET /api/factors/datasets` 会自动返回 `MyFactors`，无需改前端。

### 步骤三（如需回测）：新增对应 Handler

若新因子集需要自定义处理流程，在 `handler.py` 新增类并支持 `fields` 参数：

```python
from qlib.contrib.data.handler import DataHandlerLP

class MyFactorHandler(DataHandlerLP):
    def __init__(self, fields=None, **kwargs):
        self._selected = set(fields) if fields else None
        super().__init__(**kwargs)

    def get_feature_config(self):
        # 返回 (expressions, names)，若 self._selected 则按名字过滤
        ...
```

### 表达式语法说明

因子表达式使用 **qlib 表达式语法**，常用算子（见 `qlib/data/ops.py`）：

- 行情字段：`$open` `$high` `$low` `$close` `$volume` `$vwap`
- 时间算子：`Ref($x, n)`（n 日前）、`Mean`、`Std`、`Sum`、`Max`、`Min`、`Rank`、`Quantile`、`IdxMax`、`IdxMin`
- 回归算子：`Slope`（线性斜率，即 Alpha158 中的 BETA）、`Rsquare`、`Resi`
- 相关算子：`Corr`、`Cov`
- 逻辑算子：`Greater`、`Less`、`Abs`、`Log`

表达式必须能被 qlib 的 loader 正确解析，否则训练会报错。

## 5. 当前因子分类（Alpha158）

| 分类 | 因子 | 说明 |
|---|---|---|
| K线形态 | KMID, KLEN, KMID2, KUP, KUP2, KLOW, KLOW2, KSFT, KSFT2 | 开盘/收盘/最高/最低 组合形态 |
| 原始价格 | OPEN0, HIGH0, LOW0, VWAP0 | 相对收盘价归一 |
| 滚动算子 | ROC/MA/STD/BETA/RSQR/RESI/MAX/MIN/QTLU/QTLD/RANK/RSV/IMAX/IMIN/IMXD/CORR/CORD/CNTP/CNTN/CNTD/SUMP/SUMN/SUMD/VMA/VSTD/WVMA/VSUMP/VSUMN/VSUMD × {5,10,20,30,60} | 基于窗口 5/10/20/30/60 的动量/波动/量价算子 |

完整 158 个因子的名称与公式，可在页面"自定义筛选特征"面板中悬停查看，或调用
`GET /api/factors/catalog?dataset=Alpha158`。
