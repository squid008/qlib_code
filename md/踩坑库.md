# 踩坑库（索引）

> **只收"会安静地错"的坑** ✓ —— 报错类的不在这里（那些 `change_log` 里都有）。
> 每条给出：**现象**（看起来正常的样子）／**真因**／**现在由谁守着**。
> ⚠ 这里不放代码（代码会变，文档会腐）—— 只放"**怎么认出来**"和"**去哪找守卫**"。

## 1. 工具链咬自己（最容易被当成"业务 bug"排查一天）

| 坑 | 现象（**看起来正常**） | 真因 | 守卫 |
|---|---|---|---|
| **safe-delete 守卫拦批量删** | `pytest` 跑完全部用例却"没有汇总行、rc=1" | 测试收尾要删 500+ 临时文件 ⇒ 本机守卫直接**掐进程** | `score.py` 改用 **junit 落盘**判成败（不看汇总行）✓ |
| **vitest 的 clean 被同一条守卫拦** | 覆盖率读成 **0.00%**，而单跑一直是绿的 | `V8CoverageProvider.clean` 用 trash 删旧目录 ⇒ 被拦 ⇒ 没有 `coverage-final.json` | `score.py` 用 **pid+纳秒唯一目录**（不需要 clean ✓）|
| **`shutil.rmtree(ignore_errors=True)` 是假修** | "我加了清理" ⇒ 闸门照样红 | 那个 rmtree **也被守卫拦**，而 `ignore_errors` 把失败**静默吞了** | 同上（唯一目录）✓ |
| **PowerShell 给 `.py` 写 BOM** | `SyntaxError: invalid non-printable character U+FEFF` | `Set-Content -Encoding utf8` 默认带 BOM（本会话咬过 3 次）| 改文件只用编辑工具 / Python ✓ |
| **命令输出被工具吞掉** | 我以为 `tsc` 过了，CI 却红 | 输出被 watch 提示截断 ⇒ **没看到 exit code 就当通过** | 类型检查一律 `> 文件` 再读 ✓ |

## 2. 覆盖率/评分口径

| 坑 | 现象 | 真因 | 守卫 |
|---|---|---|---|
| **"文件缺行数"选目标** | 写完 41 条测试，覆盖 **一行没涨** | 那些 helper 早被端点测试**间接跑过**；缺的是"要行情数据"的分支 | 先摊开**函数级 / 行区间**再写 ✓ |
| **前端覆盖率 JSON 格式** | `KeyError: 'summary'` | vitest 的 `--coverage.reporter=json` 是 **istanbul**（`statementMap`/`s`），不是 coverage.py 的 `missing_lines`，也不是 v8 offset | 读 `statementMap` + `s` ✓ |
| **基线四舍五入** | 棘轮**永远差 0.02** 而红 | 实测 69.58 写成基线 69.6，判据是 `+0.01 >= 基线` | 基线只能**向下取整** ✓ |
| **tag 闸门只看本地** | "打了没推"也算过 | `git describe` 只认本地 | 改**远端优先**（`ls-remote`，不可达才降级）✓ |

| **绝对耗时门被负载污染** | `2224/2225`，单跑却 4/4 全过 | 它量的是"**空闲机器**上的耗时" | 失败后**静置 5s 重试一次**（两次都过才算过）✓ |

## 3. 前端测试（jsdom 与 React 的脾气）

| 坑 | 现象 | 真因 |
|---|---|---|
| **`URL.createObjectURL` 不存在** | 下载相关用例 `TypeError` | jsdom 没实现 ⇒ 必须在 `beforeEach` 打桩 |
| **`selectedFormulaIds` 是 `Set`** | `TypeError: .has is not a function`（9 条里 8 条全红）| 我按**数组**造 props ✗ |
| **`{...(props() as never)}`** | `TS2698: Spread types may only be created from object types` | `never` 不是对象类型 ⇒ `as unknown as ComponentProps<typeof X>` ✓ |
| **靠猜按钮文案** | 断言红，反复改 | 让 helper **失败时打印真实按钮清单**，照它写 ✓（比读 1000 行源码便宜）|
| **`it.skip` vs 空断言** | `expect(x).toBeTruthy()` 永真 | **真空测试比没测更糟**（让人以为有守卫）⇒ 测不了就 `it.skip` + 写清原因 ✓ |
| **首次挂载 API 被调 2 次** | "恰好 1 次"的断言红 | React 18 effect 双跑 / 内部两段加载 ⇒ 只比**增量** ✓ |
| **"空结果"依赖环境** | 本地红 / CI 绿 | 函数会去 glob **本机** `mlruns/` ⇒ 必须 `monkeypatch WORK_DIR` 到 tmp ✓ |

## 4. 编译器 / 语义（本项目特有）

| 坑 | 现象 | 真因 | 守卫 |
|---|---|---|---|
| **跨公式递推内联** | 12 条常用公式**每次启动**重编译失败（`不支持的函数：__RECUR_OUT`）| `_callee_tree` 返回**已 lowering** 的树，而 caller 展开后又跑一遍语义校验 | `semantic._INTERNAL_OPS` 白名单 + 入口挡用户手写 ✓ |
| **"自己生成、自己不认"** | 同上 | 白名单漏了内部算子 ⇒ 报自己的产物 | 同上 ✓ |
| **`DATE(x)` 折完标了"含日期值"** | `DATE(20070901)>0` 报"与 DATE 比较的这一侧算出来是 0" | 折出来的是**日序号（普通数值）** | 折完标 `False` ✓ |
| **布尔结果的"含日期值"没截断** | `KK:DATE<=…` 被别的公式调用后再比较 ⇒ 报 0.5 不是日期 | 比较/逻辑的结果是布尔 ⇒ 不该继续传日期标记 | `_BOOL_OPS` 截断 ✓ |
| **`DATE<=1997`** | 用户写 `2007-09-01`（被当减法）⇒ 静默按 1997 比 | 8 位字面量才能折 | 直接**报错**并给示例 ✓ |

## 5. 数据/回测口径（会算出"更好看"的净值）

| 坑 | 现象 | 说明 |
|---|---|---|
| **段间持仓不传递** | 净值"干净地"变好 | 旧持仓**凭空消失**（只买不卖/免费清仓）⇒ `_extract_end_position` 是唯一依据 |
| **特征顺序错位** | 数字照出、对应错列 | 复用模型必须比 `feature_names` **逐位**；读不到就跳过而不是放行 |
| **训练口径不符** | 净值累乘被抬高（v1.20.46 真事故）| 没有口径戳也要挡："**无法证明一致 ≠ 一致**" |
| **停牌日当涨停** | 剔涨停比例虚高 | 停牌 `CLOSE_RAW` 是 NaN ⇒ `mark_limit_up` 会当涨停 ⇒ 只取有真实价的样本 |
| **均值 vs 中位数混用** | 结论被少数暴涨事件主导 | 超额曲线两套口径**不可混算**（日配对 / 事件级）|
