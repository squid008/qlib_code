## P2 — 闸门覆盖不全（有闸，但只盖住一部分）

### 4. mypy 只覆盖 **18 / 97 个模块**（≈19%）

- **故意未收的三处**（都有书面理由 ✓）：`factors/parser/codegen.py`（数据流问题，改错会**生成错公式**）、
  `services/artifacts_service.py`（同一结构跨分支多类型）、`engine/charts.py`（matplotlib 签名噪声）。
- **为什么是债**：v2.10.45 那个「硬过滤一用就 `TypeError`」就是 **mypy 抓到的** ✓ ——
  没被覆盖的 79 个模块里，同类问题**只能靠人踩** ✗。
- **还法**：一次收 3~5 个文件到 `pyproject.toml` 的 mypy 列表 ✓，红了就修 ✓（别一次性开 79 个 ✗）。
- **成本**：每个文件 0.5~2 小时。

### 5. 前端覆盖 **39.23%** —— 巨型组件的**主链路**未测

- **已有**：4 个巨型组件各有 4~8 条**骨架**（打开/关闭/不该发的请求/空数据不崩 ✓）。
- **未测** ✗：提交 / 轮询 / 取消 / 导出 / `defaultK`（用户报过"点周期 3 却显示 7 日口径"✓）。
- **为什么是债**：骨架只保证"不崩"✓，**业务语义错了照样绿** ✗。
- **还法**：先读准 `EventStudyResult` / `SingleFactorTestResult` 的**四层嵌套类型** ✓，再造夹具。
- **成本**：高（读类型是大头 ✓，不是写断言）。

### 6. 无 eslint（前端只有 `tsc`）

- **为什么是债**：`tsc` **管不了**「async 函数忘了 `await`」「`if (promise)` 恒真」这类**语义 bug** ✓。
- **还法**：`eslint` + `@typescript-eslint` 最小规则集（`no-floating-promises` / `no-misused-promises` / `eqeqeq`）。
- **卡点** ✗：本机 `npm install` 在编辑器里**会被打断**（10 秒探测）⇒ 需要一次不受打断的安装 ✓。
- **成本**：一次装依赖 + 半小时配置（规则先只开 3 条 ✓，否则红一片 ✗）。

### 7. 无 secret 扫描 / SAST

- **证据**：CI 里只有 `pip-audit`（依赖漏洞 ✓），没有 `gitleaks`（密钥）/ `bandit` 或 CodeQL（代码模式）。
- **为什么是债**：**密钥误提交**是"一旦发生就得轮换"的事 ✗，越晚发现越贵 ✓。
- **还法**：CI 加一个 step：`gitleaks detect --no-git --redact`（扫工作区 ✓，无需历史 ✓）。
- **成本**：低（约 20 分钟）。
