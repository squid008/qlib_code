# 数据口径（索引 + 唯一真相所在）

> 目的：**同一个问题只有一个答案** ✓。这里不复制实现细节（会腐），只写**口径定义**与
> **代码里的唯一出处**；改口径必须同时改这里 ✓。

## 1. 价格与复权

| 口径 | 定义 | 代码出处 |
|---|---|---|
| `close` | **不复权**收盘价（原始价） | `datasource/` 落 bin 时的 `close` 字段 |
| `adjclose` | **后复权**收盘价 = `close / factor` | 同上（`factor` 来自数据源）|
| 回测成交价 | 一律用**真实可成交价**（涨停/停牌剔除后）| `engine/qlib_engine.py` 的买入/卖出取价 |
| 未来收益（label）| T+1 买入 → T+1+h 卖出 | `factors/single_test.py` 的 `label` 构造 |

⚠ **不要把 `close` 当复权价用**（除权日会凭空产生跌幅）—— 这是最容易"看起来对"的错。

## 2. 净值与绩效

| 口径 | 定义 | 说明 |
|---|---|---|
| 净值起点 | **1.0**（首个交易日）| 断言在 `tests/test_real_data_invariants.py` |
| 累计收益 | **复利**（`Π(1+r) − 1`）| 与"算术累加"**不可混比**（强策略复利显著更高）|
| 年化 | 几何年化，**252 交易日/年** | `engine/metrics.py` |
| 最大回撤 | **负数**（`max_drawdown <= 0`）| 同上 |
| Sharpe | `rf = 0` | 同上 |
| Sortino | 下行标准差用**半方差**口径 | 同上 |

## 3. 成本

| 项 | 口径 |
|---|---|
| 佣金 | 按**成交额**比例 + **最低 5 元**（金额不换算成百分数）|
| 印花税 | **仅卖出** |
| 过户费 | 沪深两市口径不同 |
| 三档成本（导出/曲线）| `0` / 往返 `0.004` / 往返 `0.008`（键为字符串 `"0.0000"` 等 ✓）|
| 首期建仓 | **不计费**（只有调仓才有换手成本）|

## 4. 样本剔除（"买不进 / 卖不出"）

| 剔除项 | 时机 | 说明 |
|---|---|---|
| 涨停买不进 | **信号日 T** 与**成交日 T+1** 都查 | 涨停价按 `limit_up` 字段，不靠猜 |
| 停牌 | T+1 无行情 | `CLOSE_RAW` 为 NaN ⇒ 视为停牌 |
| ST | 需要 `is_st` 标签 | **没勾选就根本不查 bin** |
| 创业板/科创板 | 可选 | 与 ST 同一开关族 |
| 跌停卖不出 | **未模拟**（已知局限 ✓）| 导出里会写进口径说明 |

⚠ "**0 命中也要报数**"是 ST 剔除的铁律（不许静默）；涨停剔除只在**真剔掉了**时报数。

## 5. 池子与时间

| 项 | 口径 |
|---|---|
| 股票池 | `csi300` / `csi500` / `all`；`all` = `features/` 目录下的全部标的 |
| 交易日历 | 以 `calendars/day.txt` 为唯一真相 |
| 事件研究对齐 | 事件日 T ⇒ **T+1 买入**，持有 `k` 个交易日 |
| 滚动训练分段 | 段号取 `model_info.segment`（如 `seg11` ⇒ 11），**不取数组下标** |

## 6. 缓存与"同一份结果"

| 缓存 | 位置 | 失效条件 |
|---|---|---|
| 表达式编译 | `workdir/expr_cache/` | `codegen` 语义戳变化 ⇒ 重编译（失败**不推进**戳 ✓）|
| 特征面板 | `workdir/feature_cache/` | 池子/区间/字段集变化 |
| 回测交付物 | `workdir/artifacts/`、`mlruns/` | 7 天回收（`ArtifactsRetention` 只读预测 ✓）|

⚠ **复用模型**必须同时校验：训练口径戳 + 特征顺序；任一无法证明 ⇒ **拒绝复用**（不是放行）。
