## [2.3.0] - 2026-10-15

### 公式语言新增 `DATE` 字段（"当前 K 线日期"）✓（用户 2026-10-15 点名要的 ✓）

**为什么**：公式要能**按日期分支** —— 益盟 CPX 里的"老规则只到 2007-09-01"就靠它 ✓
（此前公式语言**没有**任何时间函数，`DATE` 一直挂在"时间函数待外挂 P2"里 ✗）。

**用法**（用户写法不变 ✓，差由编译器补）：

| 写法 | 语义 |
|---|---|
| `DATE` | 字段：当前 K 线日期 |
| `DATE <= 20070901` | 编译期折右侧 ⇒ `Le($date,13757)` ✓ |
| `DATE(20071008)-DATE(20070901)` | = **37**（真实天数 ✓；8 位整数直接相减是 107 ✗） |
| `DATE <= 2007-09-01` | **友好错**（`2007-09-01` 语法上是 1997 ✗，绝不静默比错 ✗） |

**★ 内部值 = 日序号，不是 YYYYMMDD** ✗（硬约束 ✓）：qlib 字段 bin 是 float32
（精确整数上限 2²⁴ = 16 777 216）⇒ 实测 `np.float32(20260305)=20260304`、
`np.float32(20070901)=20070900` ✗✗（2016-07-23 之后全部失真 ✗，连截止日自己都对不上 ✗）；
日序号（~2 万）精确 ✓。口径只写一处：`app/factors/calc_date.py` ✓。

**两条求值路径同值** ✓：面板路径由 index 现合成（`panel_expr.field("$date")` ✓ 零 IO）；
qlib 路径读物化 bin（新工具 `backend/tools/dump_date.py` ✓，`--all-datasets` 写 cn_data + cn_data2，
6141 / 6144 只 ✓；`cn_data3` 按用户口径不写 ✓）。**换数据集要重跑**（header 是"该数据集日历里的下标"✗）。

**停牌删行** ✓：`$date` 登记进 `engine/feature_cache._SR_FIELDS_BY_CLOSE_MASK`
⇒ `SR($date,$close)` ✓（它每根都有值，不删会把停牌行"外对齐"回来 ✗）。

**手册** ✓：`frontend/src/formulaHandbook.ts` 加 `DATE` 条目（两条自动守卫会立刻查出"后端加了、
手册忘了" ✗）；中文别名 `日期` 登记在 `FIELD_ALIAS_GAP` / `KNOWN_GAP`（手册只扫 ASCII 名字 ✓）。

**测试** ✓：`backend/tests/test_date_field.py`（23 passed ✓）—— 日序号往返/个例锚点、折字面量、
友好错、纯常量公式仍报错、inputs 上报、SR 掩码，以及 datareq 用例**逐位对拍**
"面板合成值 == 物化 bin 值 == 该行日期本身" ✓。

**兼容性**：无存量影响 ✓（核实公式库里没有任何公式用 `DATE`/`日期` 当变量名或输出名 ✓，
`workdir/custom_formulas.json` 0 命中 ✓）；⚠ 但`日期`/`DATE` **从此不能再当变量名/输出名** ✓
（会报"是行情字段，请换名"✓，这是预期行为 ✓）。
