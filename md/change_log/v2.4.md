## [2.4.4] - 2026-10-15

### 修 v2.4.3 的**致命 bug**：装配段引用了内层函数的局部变量 ✓（CI 的 ruff `F821` 抓到 ✓）

**症状** ✗：v2.4.3 里 `_exit_mask / _exit_cache / _exit_stats` 定义在**内层函数** `_run_shared` 内，
却在 `_run` 的**装配段**（`t.join()` 之后）使用 ⇒ 运行时 **NameError** ✗；而 `_exit_stats` 是
**无条件**取的 ⇒ **每个单因子测试**都会在装配段炸 ✗（任务停在 `running` ⇒ 界面上像卡死 ✗）。

**为什么本地没抓到** ✗：① 那条路只有**真跑一次**单因子测试才会走到，而新加的测试覆盖的都是"零件"
（引擎语义 ✓ / 前置校验 ✓ / 进度模型 ✓）⇒ 没覆盖这条装配路径 ✗；② 本地**漏跑了 `ruff`** ✗
（CI 里 `ruff check app tests tools` 是独立一步 ⇒ 它一次报出 3 条 `F821` ✓）。

**修法** ✓：离场结果改走**外层**的一个小箱 `_exit_box`（内层**写**、外层**读** ✓ —— 不改嵌套
函数语义、不加 `nonlocal` ✓），装配段改读箱里的 `mask/stats/cache` ✓。

**教训**（也写进了 `md/开发记录.md` ✓）：
1. **嵌套函数里"新增的局部变量"在外层不可见** ✗ —— 跨作用域要么 `nonlocal`、要么用**可变容器** ✓；
2. **推送前本地必须跑一遍 `ruff`** ✓ —— 静态检查是**提前量最大**的那道闸 ✓（这次就是它先发现的 ✓，
   而我的 pytest 全绿 ✗ 给不了这个信息 ✓）。

## [2.4.0] - 2026-10-15

### 公式语言新增**递推组**（自引用/互引的递归变量）✓（用户 2026-10-15 定稿「直接一次做递归」✓）

**为什么**：公式语言原来**没有**"上一根的自己"✗（`A:=REF(A,1)+1;` 直接报"循环引用"✗）⇒ 每个
递归指标（趋势线 / EMA / 各种带状态算法）都得在 `ops_ext.py` 里**加一个原生算子 + 发版** ✗。
用户明确否掉这条路（「以后每个递归都要加算子那是不是不好？」✓）⇒ 做成**语言特性** ✓。

**用法**：

| 写法 | 语义 |
|---|---|
| `A:=REF(A,1)+1;` / `A:REF(A,1)+1;` | 自引用 ⇒ 递推成员 ✓（`:=` 与输出线 `:` 都支持 ✓） |
| `REF(A,k)`（k 常量 ≥1） | 组内取**上一根**（`A` 为递推成员时 ✓） |
| 组内**同根**引用 | 只允许引用**先定义**的成员 ✓（每根按定义顺序推进 ✓）；否则报错并提示换顺序或用 `REF` ✓ |
| 初值 | `REF` 越界取 **0** ✓（用户："首个没有值一般通行做法默认 0" ✓） |
| 需要"锁住头几根" | 用现成写法 `IF(BARSCOUNT(C)<=3, 0, …)` ✓（不需要新语法 ✓） |

**实现**：编译成内部算子 `RecurOut(j,N,body…)` / `RecurPrev(j,k)` / `RecurCur(j)` ✓
（用户看不见 ✓；整组带在表达式里 ⇒ 面板按表达式结构缓存 ⇒ 用多个成员也只算一次 ✓）；
面板侧拆成"骨架 + 预计算子树"，`unstack` 成 (日期×股票) 后 `recursion.run_group` **逐根 O(N) 推进** ✓。

**三条硬约束**（都写进注释与文档 ✓）：① **O(N)** 一遍推进（⇒ 不做 qlib 算子：qlib 算子逐股调用，
会慢一个量级 ✗）；② **全程 float64** ✗ 不能降精度（用户脚本 `STEP` 上限 `0.02×10 = 0.19999999999999998`
仍 `< 0.2` ⇒ 会再加一次到 ≈0.22 ✓；若中途 float32 则变成 `0.20000000298023224` ⇒ 判据翻转 ✗✗，
单测数值钉死 ✓）；③ **停牌/无 K 线的行 ⇒ 状态冻结 + 输出 NaN** ✓（益盟"无停牌行"口径 ✓）。

**qlib 路径**：注册同名**占位算子**，一求值就报清楚的中文提示 ✓（不是 `is not registered` 天书 ✗）
—— 递推组目前**只在面板路径**（单因子测试 / 事件研究）支持 ✓。

**测试** ✓：`backend/tests/test_recursion.py`（19 passed ✓：编译产物 / 同类报错（同根成环沿用老错、
同根引用后定义、`REF` 写法不合规）/ 内核数值（累加、同根读、停牌冻结、越界默认 0、窗口算子报错）/
float64 锚点 / 面板 datareq（真实数据上每股正好 1,2,3… ✓）/ qlib 报错文案 ✓）。
另做**存量公式零回归核对** ✓（66 条重编译，65 条逐字相同 ✓；唯一不同的 `深跌2` 是 `v1.20.83`
