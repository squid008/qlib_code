## 研报 1：中金《大模型系列（7）：基于 Loop Engineering 的自动化因子发现引擎》

- **来源**：中金公司研究部「中金点睛」，2026-08-03，作者郑文才/周萧潇/刘均伟
- **收录日期**：2026-08-31
- **一句话**：用大模型驱动的自动化闭环（生成—审查—验证）做价量因子挖掘，581 轮迭代跑出 69 个独立因子、Top5 复合超额夏普 3.14

### 1. 核心框架：Loop Engineering 三步闭环

| 环节 | 功能 | 实现方式 |
|---|---|---|
| **生成** | 供给候选因子 | 五种策略（见下）按比例随机调度 |
| **审查** | 规则过滤 + LLM 精判 | 硬规则先滤 + Sub-agent LLM 判断（与生成隔离，防自我说服） |
| **验证** | 回测 + 联合过滤 | 硬编码回测（不调 LLM，省时间），11 项指标联合过滤 |

大模型应用四阶段演进：`Prompt Engineering → Harness → Loop → Graph`（本项目处于 Loop 阶段）。

### 2. 因子生成五种策略（占比）

| 策略 | 占比 | 说明 |
|---|---|---|
| 变异 | 25% | 替换表达式树叶子节点/子树，保留结构骨架引入新信号源 |
| 交叉 | 25% | 交换两个父本因子子树分支，产生混合结构 |
| 参数扰动 | 15% | 动量引导下微调窗口参数，步长随梯度自适应 |
| 随机探索 | 15% | 数据驱动特征分布引导，防局部最优 |
| LLM 机制引导 | 20% | 按机制分类（定义 13 个机制族）探索未覆盖方向 |

### 3. 关键工程机制

- **检查点文件**：记录已测因子哈希集合 + 入库因子信息 + 迭代计数，支持断点续跑
- **FSA 频繁子树规避**：定期统计因子结构频次，超过 **15% 阈值**的骨架冻结禁用
- **11 项联合过滤**：含 `|IC|>0.03`、2025/2026 超额>0、夏普>0.5、Calmar>1.0、IC 相关性<0.70 等
- **Hooks**：每轮迭代结束自动输出因子库状态摘要
- **Skill 封装**：项目背景/算子/回测参数/工程约束固化为可复用模块（改数据源或资产只需改 Skill 文件）

### 4. 算子与字段体系

- 14 种算子 + 13 个派生字段（overnight、amplitude、down_shadow、hl_ratio、volume、amount、mv 等）
- 高频算子：sub(94%)、ma(81%)、delta(71%)；mul/div 低频（6%/13%）
- 因子结构平均深度 3.6 层，窗口参数集中在 51–100 天（中长窗口偏好）

### 5. 回测设置

- 近 600 个交易日（2024 初–2026/07），5 日换仓，单边千一成本，Spearman 秩 IC
- 因子 10 分组，前 10% 多头，相对全市场等权超额

### 6. 关键实验结果

- **581 轮自动迭代**（每 5 分钟一轮，持续 3 天）→ 测试 16,939 候选因子 → 保留 **21 大类 69 个独立因子**（成功率 0.41%），IC 相关性均 <0.70
- 69 因子平均超额夏普 **1.60**；2025 年以来平均年化超额 **11.7%**、平均 |IC| **5.0%**
- **Top5 因子等权复合：超额夏普 3.14，年化超额 18.3%**
- 最突出单因子：跳空趋势背离因子（夏普 2.74/超额 15.5%）、振幅扩张与跳空溢价因子（夏普 2.64/超额 14.1%）
- 搜索过程三次自适应（无需人工干预）：
  1. 前 50 轮冷启动：仅入库 4 因子，overnight 权重自动提升至 4 倍、amplitude/down_shadow 2 倍
  2. 50–400 轮平稳积累，401–450 轮集中爆发（入库 51 个，占 74%）
  3. 450 轮后 FSA 触发：overnight 骨架被冻结，自动转向 down_shadow（4%→17%）和 hl_ratio（9%→17%）

### 7. 局限

- 信号源集中（overnight 出现率 85%）、仅 3 天搜索（FSA 后新方向因子夏普均值仅 0.92）、仅日频价量无基本面/另类数据

### 8. 对本项目的启示（QUANTALPHA）

- 本项目（qlib_code）已有：自定义公式因子（FormulaHandler）、单因子测试（IC/分层/按日配对检验）、回测引擎 → **生成—审查—验证 里的"验证"环节可直接复用**
- 可落地点：
  - 生成端：基于自定义公式语法（益盟/通达信）做表达式树变异/交叉，天然契合五种生成策略
  - 审查端：11 项联合过滤可直接映射到本项目单因子测试的指标（IC、ICIR、按日配对 t、分层单调性）
  - 机制端：FSA 频繁子树规避、检查点断点续跑、Hooks 状态摘要都是工程化必备
  - 派生字段：本项目已支持 `$market_cap` 等，可补 overnight/amplitude/down_shadow 等 13 个派生字段

## 研报 2：广发金工《机器学习选股训练手册》

- **来源**：广发金融工程研究（新浪财经转载，2025-06-20）
- **收录日期**：2026-08-31
- **一句话**：机器学习选股的完整实操手册——模型选择、特征准备、损失函数、预测目标四大环节的对比实验结论

### 1. 模型选择

- **GBDT 类**：LightGBM / XGBoost / CatBoost（本项目已用 LightGBM/XGBoost ✓）
- **神经网络类**：GRU / TCN / Transformer（本项目未接入，QUANTALPHA 可考虑）
- 结论：Alpha158 类手工量价特征 → GBDT 和 NN 都行；GFStyle 基本面特征 → 树模型远好于 NN（低频变化 NN 学不到时序）；原始量价 → NN 更优
- 树模型本质是**截面模型**，学不了时序规律 → 喂的特征本身要含过去一段时间信息 + 有区分度

### 2. 特征数据准备

- **特征筛选：SHAP 最优**（对比 Spearman/互信息/LGBM 重要性/STG），能减少特征数量且几乎不损失效果、提升可解释性
- **特征中性化：无改进**！对行业市值中性化后，LGBM 因子效果显著下降、GRU 无明显提升——与其做中性化，不如从预测目标下手（见下）
- **预处理：整体标准化 > 截面标准化**。截面标准化丢掉了日期间大小关系，对 NN（时序模型）影响尤其大。要"整体 Z-Score / MinMax / RobustZScore（先去极值再 Zscore）"

### 3. 损失函数选择

- **排序学习（LTR）损失优于 MSE**：PairWise（Hinge、RankNet 等）+ ListWise（NDCG 系）
- **NDCG 系损失（LambdaNDCG2 / ApproxNDCG / NeuralNDCG）多头端表现最优**（多头信息比率、超额回撤最佳），且与 MSE 因子相关性低（增量信息）
- **MSE 也能改进**：对多空两组样本加权（LSW2，提高两端权重）→ 沪深300 多头年化 18.91%→19.46%，超额回撤 -6.51%→-4.66%
- **最优方案**：三个排序损失（DCG Hinge、LambdaNDCG2、NeuralNDCG）+ MSE 的因子值**等权合成**：IC 均值 14.42%、多头年化超额 18.90%、多头超额回撤 3.82%、多空夏普 4.22

### 4. 预测目标处理

- 预测目标选**超额收益率 + CSRank 处理**最优（排除市场 Beta，只学截面差异；绝对收益率必须配截面标准化）
- **多预测周期等权合成提升稳健性**：Ret10/Ret20/Ret40 合成优于单周期（沪深300 年化超额 17.30%→18.54%，IR 1.67→1.81；中证500 也提升；中证1000 不明显——小盘反转效应强，周期错位收益递减）
- 训练方案：8 年训练 + 2 年验证，5 个随机种子取均值，只报样本外

### 5. 指增策略结果（月度调仓、双边千三、2020–2025/05）

| 策略 | 年化超额 | 超额最大回撤 | 信息比率 |
|---|---|---|---|
| 沪深 300 指增 | 10.03% | -5.42% | 2.23 |
| 中证 500 指增 | 8.41% | -10.78% | - |
| 中证 1000 指增 | 11.44% | -7.95% | 2.09 |

- 组合优化控制：行业偏离 / 市值偏离 / 个股权重偏离 / 成分股权重

### 6. 对本项目的启示（QUANTALPHA）

- **可直接落地**（本项目 LightGBM 已支持）：
  - 预测目标：本项目 label 目前是未来 n 日收益 → 可加"超额收益率 + CSRank"选项
  - 多周期合成：本项目支持不同 `n` 的 label，可训练多周期因子做等权合成
  - 损失函数：LightGBM 支持 `objective='lambdarank'`（LambdaRank），可对照 MSE
  - 样本加权：LightGBM `sample_weight` 支持多空加权
- **待扩展**：SHAP 特征筛选（本项目已有特征列表产物，可接 SHAP 分析）、GRU/TCN 时序模型、整体标准化预处理选项
- 验证方法提醒：单因子测试应与研报一致用"多头组"视角评估（本项目已有按日配对检验等）

## 研报 3：Meta-Labeling 与触发信号混合建模（方法综述，非券商研报）

- **来源**：López de Prado《Advances in Financial Machine Learning》(AFML) 第 3 章 §3.6-3.7 Meta-Labeling；配套复现与解读：ai-quant-book（waylandzhang）/ quant-learning-path / Meta-Labeling 系列博文
- **收录日期**：2026-09-07（为"0/1 触发信号训练适配"立项检索）
- **一句话**：当"连续排序信号（量价）"与"稀疏触发信号（0/1 事件/择时）"维度不同、不能硬塞进同一个回归目标时，用**两级分工**——主模型全样本学"横截面选谁（排序）"，次级分类模型（meta-labeling）学"该信号值不值得执行（时点状态/闸门）"。

### 1. 核心框架

- **主模型**：输出方向与幅度的连续信号（本项目即回归 LightGBM → score → topk 排序），照旧。
- **Meta-label 构造**：对每个主模型信号，用实际结果（Triple-Barrier 或固定持有期收益）判定"该信号最终是否正确/盈利"，得到二值 `y* ∈ {0,1}`（盈利=1）。
- **次级模型**：以 `(原始特征 X ∪ 主模型输出 score/方向)` 为输入，学习 `y*`（分类），输出 = 执行概率 `z`；交易端 `side=主模型方向, size=f(z)`——**z 只改仓位/过滤，不改方向与排序**。
- **为什么有效（机制）**：01 触发与量价维度不同（一个管"何时/什么状态该出手"，一个管"截面选谁"），同目标回归互相稀释（极小叶子被 min_data_in_leaf 剪掉、IC≈0）。Meta-labeling 把"条件性"显式建模：主模型获得稠密梯度专心排序，次级模型专门学习事件/状态条件下的执行价值，各自避免对方噪声。
- **关键工程点**：meta-label 高度不平衡（多数 0）→ 用 ROC-AUC / precision 评估而非准确率；次级模型训练需要"主模型在样本内的预测"来构造，存在两段级联，防过拟合与数据泄漏是重点；主模型换/不换，次级模型都要相应重训。

### 2. 关键数据（第三方复现，AFML 原文为方法框架）

- SP500 验证集：模型准确率 0.2→0.77，正确交易 precision 0.21→0.39（布林均值回归策略 + 元标注，年化/回撤改善）
- 公开解读共识：元标注不是提升"预测准"，而是把"交易执行层"的胜率提升显式建模——适合信号有真 alpha 但裸执行损耗大的场景

### 3. 变体谱系（本项目立项时的备选路线，改动面从轻到重）

| 路线 | 做法 | 定位 |
|---|---|---|
| R1 稠密化 | 01 转信号年龄(BARSLAST)/强度/热度(SUM)等连续特征再入模 | 特征层，零管道改动，基线 |
| R2 加权/条件 | 同模型内对触发样本过采样/sample_weight/scale_pos_weight | 小改动，权重难调 |
| **R3 Meta 门控（本文推荐）** | 主模型不变 + 次级分类模型做 gate（两段训练） | 语义最贴合、文献主答案 |
| R4 任务改造 | label 改涨/跌分类，LightGBM 切 binary/multiclass | 与连续排序目标分叉 |

### 4. 对本项目的启示（qlib_code → 0/1 触发信号训练适配）

- **角色映射**：现回测回归 LightGBM = 主模型（量价连续 → score → topk）；趋势顶底离开底部等触发因子（01）作为次级模型输入的"时点状态特征 + 触发日样本池"。
- **落地接口预留三件套（默认值=现状，可回退）**：
  - `TaskSpec`：label 构造（回归收益 / 方向二值 / 多分类）+ objective（mse/binary/multiclass）+ 是否注入主模型预测列
  - `ScoreComposer`：预测后合成最终排序分（single 现状 / rank 加权 / gate = score×z 或 z 白名单内选 topk）
  - `Gate/Filter`：下单前可选按 01 信号或次级模型过滤
- **评估与隔离**：产物目录按任务隔离 + `train_signature.json`（参数 MD5），meta gate 路线与 baseline 可并行回测、按日配对/回测指标对比、随时回退到 single。

## 研报 4：华泰金工《再论A股择时：多维度融合》

- **来源**：华泰证券金融工程，2025-05-29，林晓明/韩晳（新浪财经转载 2025-05-31）
- **收录日期**：2026-09-08（为 all00 逃顶改造/择时立项检索）
- **一句话**：ERP + 融资买入额 + 布林带/涨跌成交额差 + 期权沽购比·隐波·期货持仓等底层指标，按"同维投票 → 四维度 → 左(估值+情绪)/右(资金+技术) → 综合"分层合成，对万得全A(2010-2025) 年化约 22%、夏普约 1.0（基准年化 3.77%），胜率 55-60%、赔率约 2

### 1. 底层指标与维度划分
| 指标 | 维度 | 性质 | 用法 |
|---|---|---|---|
| 股权风险溢价 ERP | 估值 | 左侧/逆向 | 1/PE − 无风险利率，历史高位买入、低位卖出 |
| 融资买入额 | 资金 | 右侧/顺势 | 布林带突破上轨做多、下轨做空 |
| 布林带 | 技术 | 右侧/顺势 | 通道突破 |
| 个股涨跌成交额占比差 | 技术 | 右侧/顺势 | 平滑至月频后按同比定方向 |
| 期权沽购比 PCR | 情绪 | 反向/左侧 | 成交PCR倒数反向布林；持仓PCR同比动量 |
| 期权隐含波动率 IV | 情绪 | 反向/左侧 | 反向布林带 |
| 股指期货会员持仓比 | 情绪 | 左侧/同向 | 前20会员持买单/卖单，正向布林 |

### 2. 融合方式（分层合成 + 简单投票，只留方向不留仓位）
技术=布林+涨跌成交额差；情绪=沽购比+隐波+会员持仓 → 两两投票合成四维度 → 左侧=情绪+估值、右侧=资金+技术 → 综合信号。对比：底层直接合成夏普最低；按四维度合成最佳(夏普约1)；按左右侧合成居中(约0.91、年化约18%)。PBO 检验：四维度方案约75%采样样本内最优且样本外稳定前50%。

### 3. 关键数据与结论
- 单指标历史效果：ERP 全区间夏普仅约 0.17，主要负收益来自 2015 牛市后半程踏空（信号稀疏）；融资买入额夏普约 0.6（2021 后样本外升到 1.06）；布林带约 0.14（趋势好震荡差、2021 后样本外为负）；个股涨跌成交额差约 0.25（快涨滞后）；期权隐波"显著优于沽购比"；期货会员持仓为较稳健左侧指标（样本外高胜率、赔率>1）
- 对不同宽基泛化：对中小盘增益大（中证2000最优），大盘弱。分市值归因：**资金/技术对小盘择时最有效，估值(ERP)对大盘好、对小盘为负，情绪对各指数均正（中证500/1000最佳）**
- 案例：2015-06-12 大顶，右侧指标 06-19 平仓、06-25 转空（左侧右侧互补）

### 4. 对本项目启示（QUANTALPHA / all00 逃顶层）
- 估值(ERP/PB)单指标太慢会踏空牛市后段 → 必须配右侧(资金/技术)信号
- all00 组合含 1/3 小市值 → 按分市值归因最缺"资金维度"，PB 择时天然偏弱
- 融合用"投票+只留方向"，而非单信号硬切仓位；可映射为组合层 0.5/0.75/1.0 三档投票

## 研报 5：华泰金工《多维择时模型的拆解与重构》

- **来源**：华泰证券金融工程，2026-05-18，何康/韩晳（新浪财经转载 2026-05-22）
- **收录日期**：2026-09-08
- **一句话**：把多因子择时拆成"追高/抄底/追空/逃顶"四条子路径分别评估各指标"擅长什么场景"，再用"子维度等权/路径优选"把离散信号升级为连续得分→分档仓位，日频夏普最高 1.72

### 1. 四路子路径评估框架（择时信号质量诊断）
以信号转向=开仓、同向持续=持仓，按"持仓方向×开仓时市场(5日收益符号)"划四类：追高(多+上行)、抄底(多+下行)、追空(空+下行)、逃顶(空+上行)。**场景难度递增：追高 < 抄底 < 逃顶 < 追空**。单因子择时夏普大多 0.3-0.8，合成到子维度后 0.5-1 左右，多数子维度优于成员因子（1+1>2）。

### 2. 各维度"擅长场景"结论（对本项目最关键）
- **估值维度**：追高/抄底/逃顶/追空四种场景均有正收益，追空相对弱；趋势行情中极少发信号 → 逃顶第一可靠维度
- **资金维度**（会员持仓等）：追高最佳、其次逃顶；"右侧入场、左侧离场" → 逃顶第二维度
- **情绪维度**：抄底好、逃顶不佳（成交额PCR倒数逃顶反而累计负收益，提示过热过早）
- **技术维度**：量价趋势类(ADX、60日换手乖离)仅适用于追高；异动类可抄底；期权隐波(如110IV)除逃顶外各场景均不错

### 3. 融合模型与效果（离散信号→连续得分→分档仓位）
26 底层因子 → 投票合成 12 子维度 → 归类估值/情绪/资金/技术 4 大类。
- A₁ 分层合成（各层取均值保留强度）：五档日频夏普约 1.48；周/半月约 1；月频 0.6-0.7
- A₂ 子维度等权合成（跳过大类，提高情绪技术权重）：七/九档约 1.50，年度正收益 100%
- B 路径优选（每条路径只留该场景夏普前8子维度）：九档日频夏普约 1.72（有过拟合风险）；周/半月 1-1.3、月频 0.8-1.2
- 结论：**"方向大于强度"**，阈值0 多空或五档已够用；**降频到周/月仍显著优于不择时**
- 场景检验：极端行情(±3.5%)预判/反应正确率约60%；拐点识别率 A₂ 52.9%、B 61.8%；但 2024-10-08 顶部三模型当日均强烈看多、一路到 10-16 未翻空，完整错过该次回调 → 预测顶不可靠，须配止损/熔断纪律

### 4. 对本项目启示（QUANTALPHA / all00 逃顶层）
- 逃顶靠估值+资金，情绪技术只追势 → all00 的 PB 择时属"估值"方向正确但需补资金/右侧确认
- 分层分档仓位(0.5/0.75/1.0)+投票 = 现组合 0.5/1.0 二档硬切的升级路径
- 周频执行衰减后仍有效，匹配 all00 周调仓节奏
